# Project case studies

Store all individual project pages in this directory.

## How to add a new case study

1. Duplicate `project-case-study-template.html`.
2. Rename it using a slug (for example: `nba-team-performance-analytics.html`).
3. Update page metadata (`title`, `description`) and content sections.
4. Link to it from `../projects.html` and, if relevant, `../index.html`.

## Link conventions

- From any page, use root-absolute links (for example: `/projects/nba-team-performance-analytics.html`).
- Keep CSS/JS links root-absolute as well (for example: `/css/styles.css`, `/js/portfolio.js`).

Case Study | Machine Learning

NBA Team Performance Analytics & ML Pipeline

This project turns 300K+ NBA game records into interpretable team-performance archetypes using K-means clustering and PCA. The stack combines robust scraping, feature engineering, and unsupervised learning to surface patterns that correlate with postseason success. The final output is a reproducible analytics workflow that supports coaching strategy and front-office decision-making.

Data Volume 300K+ games
Core Methods K-means + PCA
Pipeline Checkpointed ETL

The Goal

I built this to test whether PCA-reduced feature spaces can predict playoff-level team profiles more clearly than raw box score dimensions alone.

  • Identify interpretable team archetypes that coaches and analysts can actually use.
  • Compare raw-stat clustering versus PCA-space clustering for stability and separation.
  • Create a repeatable workflow that can be refreshed each season with minimal manual effort.

Data & Methods

These visuals show the modeling stages stakeholders care about most: feature compression, cluster behavior, and cluster interpretation.

Key Takeaways

  • A lower-dimensional PCA representation made cluster boundaries more stable and easier to explain to non-technical stakeholders.
  • The pipeline design improved iteration speed by allowing partial reruns via checkpoints instead of full dataset rebuilds.
  • Combining quantitative output with labeled tactical archetypes made the analysis more actionable than raw model metrics alone.
